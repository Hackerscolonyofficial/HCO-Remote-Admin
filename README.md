# HCO Remote Admin (Educational Tool)

HCO-Remote-Admin is a lightweight client-server utility built using Python's `socket` and `subprocess` libraries. This project was developed by **Hackers Colony** purely for **educational and cybersecurity awareness purposes** to demonstrate how network connections and remote command executions work under the hood.

---

## 🚀 Tool Features
* **Simple TCP Socket Communication:** Establishes a direct connection between a server and a client device.
* **Remote Command Execution:** Allows testing and running terminal commands securely within a controlled environment.
* **Lightweight & Fast:** Built entirely in Python, making it easy to run on Termux (Android), Linux, or Windows.
* **Open Source:** Fully transparent code for learners and cybersecurity enthusiasts.

---

## 🛠️ Installation & Usage Guide

Follow these steps to set up and run the tool locally for educational testing:

### 1. Clone the Repository
Open your terminal (Termux or Linux) and clone the repository:
```bash
git clone https://github.com/Hackerscolonyofficial/HCO-Remote-Admin.git

cd HCO-Remote-Admin
```
2. Run the Server
Start the server script on your primary control device:
```
python server.py

```
3. Run the Client
In a separate terminal or test environment, run the client script:
```
python client.py

```
